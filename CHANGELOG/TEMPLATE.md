# Change history format

Keep one history for each changed surface. New dated entries go below the heading, above older entries; never rewrite earlier entries. Link each history from [README.md](README.md).

## Entry template

```md
## YYYY-MM-DD — Short imperative title
Explain what changed, why, and the reader-visible effect in one to three sentences.
**Commit**: resolve through Git history for this path. **Author**: name.
**Validation**: exact checks and observed result; distinguish source checks from runtime proof.
**Limits**: what this change does not verify.
```
